📸Tirar print (captura de tela)

O print é a prova mais rápida de um problema. Prefira recortar só a área que importa e, se tiver dado sensível, rabisque por cima antes de enviar.

AtalhoO que fazDica
Windows
Win + Shift + S
Abre a Ferramenta de Captura: você escolhe retângulo, janela, tela inteira ou forma livre.O print vai para a área de transferência: é só Ctrl + V no WhatsApp ou no chamado. Clique na notificação para rabiscar, destacar ou salvar.
Windows
PrtSc
Captura a tela inteira (no Windows 11 atualizado, pode abrir a Ferramenta de Captura).Em notebooks a tecla pode se chamar PrtSc, PrtScn ou Print e às vezes precisa de Fn junto.
Windows
Win + PrtSc
Captura a tela inteira e salva o arquivo automaticamente.Fica em Imagens › Capturas de Tela. A tela pisca para confirmar.
Windows
Alt + PrtSc
Captura só a janela ativa (ex.: só o Chrome).Bom quando o cliente tem dois monitores. Vai para a área de transferência.
Mac
Cmd + Shift + 3
Captura a tela inteira.Salva na Mesa (Desktop).
Mac
Cmd + Shift + 4
Captura uma área: arraste para selecionar.Apertando Espaço depois, captura uma janela específica.
Mac
Cmd + Ctrl + Shift + 4
Captura uma área e copia direto para a área de transferência.Depois é só Cmd + V para colar.
Mac
Cmd + Shift + 5
Abre a barra de captura (print e gravação de vídeo).Em “Opções” dá para escolher onde salvar e ativar o temporizador.
Chrome
F12 → Ctrl + Shift + P → digite full
Print da página inteira do site, mesmo a parte que precisa rolar.Escolha “Capture full size screenshot” e o PNG baixa sozinho. Ótimo para mandar o cardápio inteiro ou uma tela longa do painel.
Android
Liga/desliga + Volume -
Print da tela no Android.Aperte os dois juntos e solte. Em alguns aparelhos dá para deslizar 3 dedos para baixo. Fica na Galeria › Capturas de tela.
iPhone
Botão lateral + Volume +
Print no iPhone com Face ID (iPhone X em diante).Aperte e solte rápido. A miniatura aparece no canto: toque para rabiscar. Fica em Fotos.
iPhone
Botão lateral + Início
Print no iPhone com botão de início (iPhone 8, SE).Em modelos muito antigos é o botão de cima + Início.

🎥Gravar vídeo da tela

Vídeo é a melhor evidência para erro que “às vezes acontece” ou fluxo com vários passos. Grave curto (até 1 minuto), mostrando o caminho desde o início.

AtalhoO que fazDica
Windows
Win + Shift + R
Inicia a gravação de tela da Ferramenta de Captura (Windows 11 atualizado): selecione a área e clique em Iniciar.Se o atalho não abrir, use Win + Shift + S e clique no ícone de câmera. Dá para ligar microfone e som do sistema. O vídeo fica em Vídeos › Gravações de Tela.
Windows
Win + Alt + R
Grava o aplicativo aberto pela Xbox Game Bar (Windows 10 e 11).Não grava a área de trabalho nem o Explorador de Arquivos, só o programa em foco (ex.: Chrome). Win + Alt + R de novo para parar. Fica em Vídeos › Capturas.
Windows
Win + G
Abre a Xbox Game Bar (gravação, microfone, captura).Se não abrir: Configurações › Jogos › Xbox Game Bar e ative.
Mac
Cmd + Shift + 5
Abre a barra de captura: “Gravar tela inteira” ou “Gravar parte selecionada”.Para parar, clique no ícone de parar na barra de menus. Em Opções dá para ligar o microfone.
Android
Puxe a barra de notificações → Gravar tela
Gravação de tela no Android (Android 11 em diante).O nome muda: “Gravador de tela” (Samsung), “Gravação de tela” (Motorola/Xiaomi). Se não aparecer, toque no lápis para adicionar o botão.
iPhone
Central de Controle → ⏺ Gravação de Tela
Gravação no iPhone.Se não tiver o botão: Ajustes › Central de Controle › adicionar “Gravação de Tela”. Toque e segure para ligar o microfone. Para parar, toque na barra vermelha no topo.

🌐Navegador (Chrome) — dia a dia e resolver problemas

Quase todo atendimento passa pelo navegador. No Mac, troque Ctrl por Cmd.

AtalhoO que fazDica
Chrome
Ctrl + F5 ou Ctrl + Shift + R
Recarrega a página sem usar o cache.Primeira coisa a pedir quando “não atualizou”, “sumiu o botão” ou “ainda aparece o preço antigo”.
Chrome
Ctrl + Shift + Delete
Abre Limpar dados de navegação.Marque “Imagens e arquivos em cache” e “Cookies”. Atenção: cookies desconectam as contas, então avise o cliente antes.
Chrome
Ctrl + Shift + N
Abre uma janela anônima.Testa sem cache, sem extensões e sem login salvo. Se funcionar na anônima, o problema é cache ou extensão.
Chrome
Ctrl + Shift + T
Reabre a aba fechada por engano.Pode apertar várias vezes para voltar várias abas.
Chrome
Ctrl + L
Seleciona a barra de endereço.Para copiar o link exato que o cliente está vendo.
Chrome
Ctrl + F
Procura uma palavra na página.Útil para achar um produto num cardápio grande.
Chrome
Ctrl + + ou Ctrl + - ou Ctrl + 0
Aumenta, diminui ou volta o zoom ao normal.Página “cortada” ou “gigante”? Quase sempre é zoom: Ctrl + 0 resolve.
Chrome
Ctrl + Tab ou Ctrl + 1…9
Troca de aba (próxima, ou direto pela posição).Ctrl + 9 vai para a última aba.
Chrome
Ctrl + W ou Ctrl + Shift + W
Fecha a aba ou a janela inteira.
Chrome
Ctrl + J
Abre os Downloads.Para achar o instalador ou o arquivo que o cliente “baixou e não acha”.
Chrome
Ctrl + H
Abre o histórico.Para voltar a um link visitado mais cedo.
Chrome
Ctrl + P
Imprimir a página.Bom para testar se a impressora responde fora do sistema.
Chrome
F12 ou Ctrl + Shift + I
Abre o DevTools.Aba Console mostra erros em vermelho. Mande print disso no chamado para o time técnico.
Chrome
F12 → Ctrl + Shift + M
Mostra o site como no celular.Ótimo para ver o cardápio digital do jeito que o cliente final vê.
Chrome
Digite chrome://version na barra
Mostra a versão do Chrome.Útil quando o problema só acontece em um computador.

🛠️Windows — diagnóstico rápido (Win + R)

Aperte Win + R, digite o comando e dê Enter. Servem para orientar o cliente ou para usar no acesso remoto.

AtalhoO que fazDica
Windows
control printers
Abre Dispositivos e Impressoras.Clique com o botão direito na impressora › Propriedades da impressora › Imprimir página de teste. Se a página de teste não sai, o problema é a impressora ou o driver, não o sistema.
Windows
ms-settings:printers
Impressoras nas Configurações do Windows 10/11.Também mostra a fila: dá para cancelar impressão travada.
Windows
winver
Mostra a versão do Windows.Para saber se é Windows 10 ou 11 antes de instalar o sistema.
Windows
ms-settings:about
Mostra se o Windows é 64 bits (“Tipo de sistema”).O instalador do WhatsMenu Desktop é x64: precisa de Windows 64 bits.
Windows
appwiz.cpl
Programas instalados (desinstalar).Para remover uma versão antiga antes de instalar a nova.
Windows
devmgmt.msc
Gerenciador de Dispositivos.Impressora USB com ⚠️ amarelo = problema de driver.
Windows
ncpa.cpl
Conexões de rede.Ver se o Wi-Fi ou o cabo está conectado.
Windows
cmd → ping 8.8.8.8 -t
Testa se a internet está caindo.Respostas com “Esgotado o tempo” = internet instável. Ctrl + C para parar.
Windows
cmd → ipconfig
Mostra o IP do computador.Útil para impressora de rede (precisa estar na mesma faixa de IP).
Windows
%temp%
Abre a pasta de arquivos temporários.Pode apagar o que der: libera espaço quando o computador está lento.

📨Mensagens prontas para o cliente

Para quando é o cliente que precisa tirar o print, gravar o vídeo ou fazer um teste. Troque o que precisar antes de enviar.

Pedir print — computador (Windows)
Para eu entender certinho, consegue me mandar um print da tela? 😊

1️⃣ Aperte juntas as teclas *Windows + Shift + S*
2️⃣ Arraste para selecionar a parte da tela
3️⃣ Volte aqui na conversa e aperte *Ctrl + V* para colar

Depois é só enviar!
Pedir print — celular
Consegue me mandar um print da tela do celular? 😊

📱 *Android:* aperte juntos o botão de *ligar* e o de *abaixar o volume*
🍎 *iPhone:* aperte juntos o *botão lateral* e o de *aumentar o volume*

O print fica na galeria, é só me enviar por aqui.
Pedir vídeo — computador (Windows 11)
Para eu ver exatamente o que acontece, consegue gravar um vídeo curtinho da tela? 🎥

1️⃣ Aperte *Windows + Shift + R*
2️⃣ Selecione a área da tela e clique em *Iniciar*
3️⃣ Faça o passo a passo até o erro aparecer
4️⃣ Clique no botão de *parar* (quadrado vermelho)

O vídeo fica na pasta *Vídeos > Gravações de Tela*. É só me enviar por aqui!
Pedir vídeo — celular
Consegue gravar um vídeo curtinho da tela do celular mostrando o que acontece? 🎥

📱 *Android:* puxe a barra de notificações e toque em *Gravar tela*
🍎 *iPhone:* abra a Central de Controle e toque no botão *⏺ Gravação de Tela*

Faça o passo a passo até o problema aparecer, pare a gravação e me envie por aqui.
Atualizar a página sem cache
Vamos fazer um teste rápido: com a página do sistema aberta, aperte juntas as teclas *Ctrl + F5*.

Isso recarrega a página com a versão mais nova. Depois me conta se resolveu! 😊
Testar na janela anônima
Vamos testar uma coisa: aperte *Ctrl + Shift + N* para abrir uma janela anônima do Chrome, entre no sistema por ela e veja se o problema continua.

Se lá funcionar normal, já sei que é algo salvo no navegador e te ajudo a limpar. 😊
Saber se o Windows é 64 bits
Para eu te mandar o instalador certo, faz esse teste rapidinho:

1️⃣ Aperte *Windows + R*
2️⃣ Digite *ms-settings:about* e aperte Enter
3️⃣ Me manda um print da parte *Especificações do dispositivo* (onde fala “Tipo de sistema”)
Página de teste da impressora
Vamos ver se a impressora está respondendo pelo Windows:

1️⃣ Aperte *Windows + R*
2️⃣ Digite *control printers* e aperte Enter
3️⃣ Clique com o botão direito na sua impressora > *Propriedades da impressora*
4️⃣ Clique em *Imprimir página de teste*

Me avisa se saiu a folha de teste! 🖨️

✅Boas práticas de evidência

📸 Um bom print

  • Mostra a tela inteira do sistema, com a barra de endereço e a hora do computador, quando o problema é de horário/pedido.
  • Destaque o erro com a caneta ou o marca-texto da Ferramenta de Captura.
  • Esconda dados sensíveis (CPF, cartão, telefone de cliente final) rabiscando por cima antes de enviar para fora da empresa.

🎥 Um bom vídeo

  • Até 1 minuto, começando antes do problema: mostre o caminho todo.
  • Ative o Não Perturbe (Win + N) para não aparecer notificação pessoal.
  • Mexa o mouse devagar e pare 2 segundos no erro.
  • Vídeo grande demais para o WhatsApp? Suba no Google Drive e mande o link com acesso liberado.

🧾 Evidência para chamado

  • Loja (nome e e-mail do painel) e telefone do lojista.
  • O que aconteceu e o que era esperado, em uma frase cada.
  • Passo a passo para repetir o problema.
  • Data e hora em que aconteceu, e se acontece sempre ou às vezes.
  • Print ou vídeo + print do Console (F12) se for erro no navegador.
  • O que já foi testado (Ctrl + F5, janela anônima, outro computador).

Nenhum atalho encontrado. Tente outra palavra.
